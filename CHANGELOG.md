# Changelog

## 1.0.10 (2026-11-07)

- Choose the media type once for the whole batch. Options include automatic detection, movies, TV shows, documentary films and documentary episodes.
- Batch Save asks whether to overwrite selected existing NFOs. Approving overwrite brings up a separate backup choice. Declining overwrite still creates NFOs for selected videos that lack one.
- Select unreadable NFOs by row or with **Select all**. When overwrite is approved, NFO Maker builds replacements from filename suggestions and the grid. It skips parsing those unreadable files during the save.
- Delete a single NFO from the editor or preview a folder-wide deletion from Batch. The folder preview includes subfolders by default and lets you narrow the scope. Choose whether to keep `.bak` copies.
- Setup displays its version, asks before overwriting an existing installation, and prompts you to close NFO Maker if it is still running.
